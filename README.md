# Snake,water and gun game_project
It"s my first project , This is a basic project - Snake, Water, Gun game developed using the Python programming language. The project is designed as a simple command-line game where the user plays against the computer based on predefined rules. It makes use of a dictionary to map the relationships between snake, water, and gun, while if-else statements are used to control the game logic and determine the winner. Functions are implemented to organize the code and improve reusability. The project helps in understanding fundamental Python concepts such as conditional statements, functions, and data structures, and also demonstrates the use of randomness for generating the computer’s choices. An import random module is also used so the computer can choose.
